# 技术实现细节

## 1. 知识蒸馏实现

### 1.1 蒸馏损失函数

我们实现了多层次的蒸馏策略：

#### 输出层蒸馏
使用KL散度损失，将教师模型的软标签（soft labels）传递给学生模型：

```python
L_KD = KL(softmax(z_s / T), softmax(z_t / T)) × T²
```

其中：
- `z_s`, `z_t`: 学生和教师模型的logits
- `T`: 温度参数，用于软化概率分布

#### 中间层特征蒸馏
匹配教师和学生模型的中间层表示：

```python
L_hidden = MSE(h_s, h_t)
```

选择最后4层进行特征蒸馏，以平衡计算开销和效果。

#### 注意力转移
学习教师模型的注意力模式：

```python
L_attn = MSE(A_s, A_t)
```

### 1.2 总损失函数

```python
L_total = α × L_CE + β × L_KD + γ × (L_hidden + L_attn)
```

默认参数：α=0.5, β=0.3, γ=0.2

## 2. 结构化剪枝实现

### 2.1 注意力头剪枝

#### 重要性评估
使用梯度的L1范数评估注意力头的重要性：

```python
I_head = ∑|∂L/∂A_head|
```

#### 剪枝策略
- 计算所有注意力头的重要性分数
- 按重要性排序
- 移除重要性最低的30%注意力头
- 保持每层至少保留8个头

### 2.2 FFN维度剪枝

#### 重要性评估
使用激活值的均值评估FFN中间层神经元的重要性：

```python
I_neuron = E[|activation|]
```

#### 剪枝策略
- 对每层独立评估
- 保留重要性最高的75%维度
- 修改权重矩阵形状

### 2.3 渐进式剪枝
为避免性能急剧下降，采用渐进式剪枝：
1. 评估重要性分数
2. 剪枝25% → 微调5轮
3. 再剪枝至目标比例 → 微调10轮

## 3. 量化实现

### 3.1 对称量化

对于权重W，量化过程：

```python
scale = max(|W|) / (2^(bits-1) - 1)
W_q = round(W / scale)
W_dq = W_q × scale
```

### 3.2 按通道量化

对卷积和线性层，按输出通道分别计算scale：

```python
scale[i] = max(|W[i,:]|) / (2^(bits-1) - 1)
```

这样可以更好地适应不同通道的数值范围。

### 3.3 量化感知训练 (QAT)

在训练过程中模拟量化：

```python
# Forward pass
W_q = quantize(W)
W_dq = dequantize(W_q)
output = linear(input, W_dq)

# Backward pass
# 使用straight-through estimator
∂L/∂W = ∂L/∂W_dq
```

### 3.4 混合精度策略

不同层使用不同精度：
- Embedding层: FP16 (对精度敏感)
- Attention层: INT8
- FFN层: INT8
- Classifier层: FP16

## 4. 混合压缩流程

### 4.1 三阶段训练

#### 阶段1: 知识蒸馏 (20 epochs)
- 使用完整的BERT-base作为教师
- 学生模型与教师相同架构
- 学习率: 2e-5
- 优化目标: 保持性能，学习教师的知识

#### 阶段2: 结构化剪枝 (10 epochs)
- 基于蒸馏后的模型
- 计算重要性分数
- 执行剪枝
- 学习率: 1e-5 (降低以稳定训练)
- 优化目标: 恢复被剪枝损失的性能

#### 阶段3: 量化 (5 epochs)
- 基于剪枝后的模型
- 量化感知训练
- 学习率: 2e-6 (更低学习率)
- 优化目标: 适应量化带来的精度损失

### 4.2 学习率调度

使用warmup + linear decay策略：

```python
lr = base_lr × min(step / warmup_steps, 1.0) × max(0, (total_steps - step) / (total_steps - warmup_steps))
```

Warmup比例: 10%

## 5. 工程优化

### 5.1 数据加载优化
- 使用DataLoader的pin_memory
- 预先分词并缓存
- 使用多进程加载 (num_workers=4)

### 5.2 训练优化
- 梯度累积 (当显存不足时)
- 混合精度训练 (FP16)
- 梯度裁剪 (max_norm=1.0)

### 5.3 推理优化
- 批处理推理
- 使用torch.no_grad()
- 利用RTX 4090的Tensor Core加速

### 5.4 内存优化
- 及时释放不用的中间变量
- 使用gradient checkpointing (长序列时)
- 冻结教师模型参数

## 6. 评估方法

### 6.1 性能评估
- 在验证集上计算准确率、F1等指标
- 使用混淆矩阵分析错误类型
- 记录不同类别的精确率和召回率

### 6.2 效率评估
- 推理时间: 预热10次后，平均100次推理
- 内存占用: 使用torch.cuda.max_memory_allocated
- 模型大小: 计算参数量和磁盘占用

### 6.3 稳定性评估
- 使用不同随机种子重复3次
- 计算指标的均值和标准差
- 分析方差来源

## 7. 调试技巧

### 7.1 常见问题

1. **蒸馏损失不收敛**
   - 检查温度参数是否过大
   - 降低KD损失权重β
   - 增加训练轮数

2. **剪枝后性能骤降**
   - 降低剪枝率
   - 延长微调时间
   - 检查是否剪掉了关键层

3. **量化精度损失大**
   - 使用更多位宽 (如INT16)
   - 增加QAT训练轮数
   - 使用更多校准数据

### 7.2 可视化工具
- TensorBoard记录训练曲线
- 使用matplotlib绘制注意力热图
- 使用seaborn生成混淆矩阵
