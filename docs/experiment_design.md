# 实验设计文档

## 消融实验设计

### 实验目的
通过系统性的消融实验，评估各压缩方法的独立贡献和协同效果，为混合压缩策略提供理论依据。

### 实验组设置

| 实验组 | 知识蒸馏 | 剪枝 | 量化 | 预期效果 |
|--------|----------|------|------|----------|
| 1. Baseline | ✗ | ✗ | ✗ | 基线性能，无压缩 |
| 2. KD only | ✓ | ✗ | ✗ | 评估蒸馏对模型泛化的影响 |
| 3. Pruning only | ✗ | ✓ | ✗ | 评估剪枝对模型大小的影响 |
| 4. Quantization only | ✗ | ✗ | ✓ | 评估量化对存储和速度的影响 |
| 5. KD + Pruning | ✓ | ✓ | ✗ | 评估蒸馏是否能补偿剪枝损失 |
| 6. KD + Quantization | ✓ | ✗ | ✓ | 评估蒸馏是否能补偿量化损失 |
| 7. Pruning + Quantization | ✗ | ✓ | ✓ | 评估剪枝和量化的协同效果 |
| 8. Full (Hybrid) | ✓ | ✓ | ✓ | 完整混合压缩方法 |

### 评估指标

#### 性能指标
- **准确率 (Accuracy)**: 分类任务的主要指标
- **F1分数**: 对于不平衡数据集的补充指标
- **推理时间**: 单个批次的平均推理时间（毫秒）

#### 压缩指标
- **压缩比 (Compression Ratio)**: 原始模型大小 / 压缩模型大小
- **参数量减少**: (原始参数量 - 压缩参数量) / 原始参数量
- **加速比 (Speedup)**: 原始推理时间 / 压缩推理时间

#### 综合指标
- **效率-性能权衡**: 在准确率下降<2%的前提下，最大化压缩比
- **相对得分**: Score = (Accuracy / BaselineAccuracy) × (CompressionRatio + Speedup) / 2

#### 硬件配置
- **GPU**: NVIDIA RTX 4090 (24GB)
- **CPU**: 根据实际情况

- **操作系统**: Linux (Ubuntu 20.04+)
- **Python**: 3.8+
- **PyTorch**: 2.0+
- **CUDA**: 11.8+
- **Transformers**: 4.30+

### 超参数设置

#### 基线模型
- 学习率: 2e-5
- 批次大小: 32
- 训练轮数: 5
- 优化器: AdamW (weight_decay=0.01)

#### 知识蒸馏
- 温度: 2.0
- α (CE loss): 0.5
- β (KD loss): 0.3
- γ (Feature loss): 0.2
- 训练轮数: 20

#### 剪枝
- 注意力头剪枝率: 30%
- FFN维度剪枝率: 25%
- 微调轮数: 10
- 学习率: 1e-5

#### 量化
- 量化位宽: 8-bit
- 量化方式: 对称量化
- 量化范围: 按通道量化
- QAT轮数: 5
- 学习率: 2e-6

### 数据集选择

#### 主数据集: SST-2 (Stanford Sentiment Treebank)
- **任务**: 二分类情感分析
- **训练集**: 67,349条
- **验证集**: 872条
- **测试集**: 1,821条
- **选择理由**: 
  - 数据量适中，训练时间合理
  - 任务简单明确，便于评估
  - 广泛使用的基准数据集

#### 辅助数据集: MRPC (Microsoft Research Paraphrase Corpus)
- **任务**: 句子对语义相似度判断
- **训练集**: 3,668条
- **验证集**: 408条
- **测试集**: 1,725条
- **选择理由**:
  - 验证模型在句子对任务上的泛化能力
  - 数据量较小，适合快速验证
  - 需要更强的语义理解能力

### 实验流程

#### 阶段一: 基线建立 (Day 1)
1. 训练完整的BERT-base模型
2. 在两个数据集上评估性能
3. 建立性能基线和推理时间基线

#### 阶段二: 单一方法实验 (Day 2-4)
1. 知识蒸馏实验
2. 剪枝实验
3. 量化实验
4. 评估各方法的独立效果

#### 阶段三: 组合方法实验 (Day 5-7)
1. KD + Pruning
2. KD + Quantization
3. Pruning + Quantization
4. 评估方法间的协同效果

#### 阶段四: 完整混合方法 (Day 8-10)
1. 训练完整混合压缩模型
2. 详细评估和分析
3. 与所有基线对比

#### 阶段五: 结果分析和报告 (Day 11-12)
1. 汇总所有实验结果
2. 生成可视化图表
3. 撰写实验报告

### 结果记录

每个实验需要记录：
1. **训练日志**: 损失曲线、准确率曲线
2. **模型检查点**: 最佳模型和最终模型
3. **评估结果**: JSON格式的详细指标
4. **推理性能**: 时间、内存占用
5. **模型大小**: 参数量、磁盘占用

### 可重复性

为保证实验可重复性：
1. 固定随机种子 (seed=42)
2. 使用相同的数据划分
3. 记录所有超参数
4. 使用版本控制
5. 记录环境配置

### 预期结果

基于文献调研，我们预期：
1. **单一方法**:
   - 知识蒸馏: 准确率下降 <1%
   - 剪枝: 压缩比 1.5-2x，准确率下降 1-2%
   - 量化: 压缩比 3-4x，准确率下降 <1%

2. **组合方法**:
   - KD + Pruning: 准确率损失可控在1.5%以内
   - KD + Quantization: 几乎无性能损失
   - Pruning + Quantization: 压缩比 5-7x

3. **完整混合**:
   - 压缩比: 6-8x
   - 加速比: 2.5-3.5x
   - 准确率下降: <2%

### 失败预案

如果某个实验组表现不佳：
1. 调整超参数（学习率、训练轮数）
2. 修改压缩比例（降低剪枝率或量化位宽）
3. 增加训练时间
4. 使用更大的验证集进行早停
